# 🏏 Cricket Performance Analyzer

A local data analytics pipeline and interactive web dashboard built to analyze cricket match datasets. This project ingests raw CSV data into a local SQLite database, processes it using Pandas, and visualizes key metrics through a responsive Streamlit frontend.

## 🛠️ Tech Stack
* **Language:** Python
* **Database:** SQLite3
* **Data Processing:** Pandas
* **Visualization:** Matplotlib
* **Frontend Dashboard:** Streamlit

## 📂 Project Structure
```text
cricket_analyser/
├── data/
│   ├── raw/                 # Downloaded Kaggle CSVs (matches.csv, deliveries.csv)
│   └── cricket_analysis.db  # SQLite database generated by the setup script
├── src/
│   ├── setup_db.py          # Script to initialize DB and load CSV data
│   └── dashboard.py         # Streamlit frontend application
├── .gitignore               # Ignores local databases and large CSV files
└── README.md                # Project documentation
🚀 How to Run Locally
1. Prerequisites
Ensure you have Python installed. Clone this repository to your local machine.

2. Install Dependencies
Run the following command in your terminal or PowerShell to install the required Python packages:

Bash
py -m pip install pandas matplotlib streamlit
3. Add the Dataset
Download a dataset like the "IPL Matches and Deliveries" from Kaggle.

Create a folder named data/raw/ in the root directory.

Place matches.csv and deliveries.csv inside data/raw/.

4. Initialize the Database
Run the setup script to ingest the raw CSVs into the SQLite database:

Bash
py src/setup_db.py
5. Launch the Dashboard
Start the interactive Streamlit web application:

Bash
py -m streamlit run src/dashboard.py
The dashboard will automatically open in your default web browser.

📊 Current Features
Automated ETL Pipeline: Seamlessly loads raw CSV files into an organized SQL database.

Top Toss Winners View: Visualizes the top 5 teams by toss wins using Matplotlib bar charts.

Raw Data Explorer: Provides a clean, paginated data table to inspect the underlying match records directly from the database.
